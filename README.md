# The World as a Canvas

Website for **The World as a Canvas: Materializing Imagination through Prompting the Physical World**, a workshop at UIST '26 (November 2, 2026 · Detroit, MI, USA).

Live site: https://worldascanvas.github.io

## Structure

```
index.html              the whole site (HTML + CSS inline, no build step)
images/organizers/      organizer photos — see the README in that folder
```

## Editing

Edit, commit, push — GitHub Pages redeploys in about a minute.

```bash
git add -A && git commit -m "Update site" && git push
```

## Adding organizer photos

Drop square photos into `images/organizers/` using the filenames listed in
[`images/organizers/README.md`](images/organizers/README.md). They appear automatically —
no HTML editing needed. Until a file exists, that person shows a red circle with their initials.
