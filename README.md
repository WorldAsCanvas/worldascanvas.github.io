# The World as a Canvas

Website for **The World as a Canvas: Materializing Imagination through Prompting the Physical World**, a workshop at UIST '26 (November 2, 2026 · Detroit, MI, USA).

Live site: https://worldascanvas.github.io

## Editing

The whole site is a single self-contained file: `index.html` (HTML + CSS inline, no build step, no dependencies).
Edit it, commit, and push — GitHub Pages redeploys in about a minute.

```bash
git add index.html && git commit -m "Update site" && git push
```
